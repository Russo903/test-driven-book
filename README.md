# Gino's TDD Journey

A hands-on follow-along of **Test Driven Development: An Practical Guide** by Lasse Koskela, worked through in Java with JUnit.

## About

This repo tracks my progress through the book. Both the code exercises and my notes as I go. The goal is to build a real understanding of TDD from the ground up: writing tests first, letting them fail, then making them pass, and refactoring with confidence.

## What's Inside

- **Exercises** - code written chapter by chapter, following the book's examples and challenges
- **Notes** - observations and things that clicked along the way

## Tech

- Java
- JUnit

## Approach

Each piece of functionality starts with a failing test. No production code gets written without a test driving it first. Commits are kept small and intentional to reflect the TDD rhythm the book teaches.

## Why TDD

I'm learning TDD because I want to write code I can trust and refactor without fear. This book is teaching me that tests aren't just a safety net, they shape how you design software from the start.
